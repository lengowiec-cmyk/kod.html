# Realizacja opisu PRZECZYTAJ.txt

| Obszar z załącznika | Realizacja w PDFManager 0.6 |
|---|---|
| Manage / Cabinets / Drawers | Szafki wskazujące katalogi, szuflady pierwszego poziomu, filtr szuflad, foldery, pliki i podgląd |
| Przenoszenie i nazywanie | Menu listy plików, wielokrotny wybór, kopiowanie/przenoszenie/zmiana nazwy, reguły nazw importu |
| Search | Nazwa, zaszyfrowany indeks treści PDF, OCR, podfoldery, typ i daty; katalogi sieciowe dostępne przez Windows |
| Inbox | Dwie listy: folder przychodzący i docelowa szafka; przeciąganie/kopiowanie; operacje nazw w menu listy |
| Edit / PDF | Zachowane i zabezpieczone operacje tekstu, czcionek, stron, formularzy, adnotacji, scalania i dzielenia |
| Scan | WIA, aplikacja producenta TWAIN i import plików; biblioteka profili przetwarzania skanów |
| OCR | Tesseract, pol/eng/ukr, przeszukiwalny PDF lub tekst, zakresy stron, OCR automatycznego importu |
| Folder Templates | Biblioteka z dodawaniem, edycją, usuwaniem, drzewem podglądu i utworzeniem klienta |
| Settings | Dziesięć kategorii; tylko działające ustawienia lub wyjaśnienia dostępnej integracji |
| Automate | Własne reguły według nazwy, tekstu lub kodu; ręczna obróbka i kierowanie w obserwatorze folderu |
| Receipts | Własna ewidencja wydatków z PDF, kategoriami, kwotami, sumami walut, zwrotem i eksportem CSV |
| Kody kreskowe / routing | ZXing, QR i formaty 1D/2D; reguły oparte na treści kodu |
| Portal / udostępnianie | Własne przygotowanie paczki ZIP i istniejąca integracja Drive; bez kopiowania usługi producenta |

Nie kopiowano podziału na komercyjne edycje innego produktu. Zaimplementowane
narzędzia tworzą jeden program. Nie dodano pozornych checkboxów sprzętowych:
dupleks, podajnik i rozmiar papieru zależą od sterownika skanera. WIA pobiera
pojedynczy obraz, a wielostronicowe skany można odbierać jako TIFF/PDF.

Warunki kierowania są dosłownymi frazami, a nie skryptami lub wyrażeniami
wykonywanymi jako kod. „Kody i separatory” odsyła do rozpoznawania oraz podziału PDF na części
rozpoczynające się stroną z kodem. Strony z kodami są zachowywane w wynikach.
Przesuwanie i skalowanie dotyczy elementów wstawionych tym modułem programu.
